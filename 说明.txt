========================================
 Longshot 中文化补丁（简体中文）v1.3.3
========================================

适用版本：
  游戏        Longshot v3.1.1（官方预编译版或自己编译的都可以）
  启动器      Longshot Launcher v1.2.0 / v1.3.0

安装步骤：
  1. 完全退出游戏和启动器
  2. 双击  安装游戏汉化.bat
     ★ 它不再替换整个 DLL，而是把译名写进**你自己电脑上原本那份**
       bin\longshot_vk.dll：只追加一个 .zhcn 节放译文、改翻译表里的指针，
       翻译表里没有的条目则就地改写 DLL 里硬编码的英文名。代码段一个字节都不动。
       这样就不会出现"别人的构建和你的构建不一样 → 载入存档时崩溃"。
  3. 双击  安装启动器汉化.bat
  4. 打开启动器 / 进游戏按 Insert，界面即为中文

菜单显示中文的前提：
  - 游戏文件夹里 language.txt 是 zh-Hans
  - Insert 菜单 → Language / 语言 → Menu language / 菜单语言 = 简体中文
    （或 Auto (game's language)，跟随游戏语言）

自定义译名（想改哪个名字就改哪个）：
  1. 用记事本打开 自定义翻译.txt，改等号右边
  2. 保存，双击 应用自定义翻译.bat
  3. 游戏里重开一次 Insert 菜单即可看到
  注意：如果脚本提示"中文比英文原名长，原位放不下"，把那一条的译名改短一点再跑。

遇到问题：
  - 崩溃了：双击 收集崩溃信息.bat，会生成 崩溃摘要.txt（DLL 状态、崩溃记录、日志结尾、设置、显卡驱动）
  - 想恢复英文：双击 还原原版.bat

v1.3.3 改了什么：
  1. 安装方式改为"改写你自己的 DLL"，不再整份替换 DLL
     —— 修掉"装完进游戏、载入存档时崩溃"的问题
  2. 翻译表里找不到的条目，会就地改写 DLL 里硬编码的英文名；中文比英文长、原位放不下时，会自动改成「改指针」的方式（长度不限）
  3. 译名表补全：菜单各页的界面文字（约 1100 条）+ 124 个道具/地点名，共 1169 条；
     .zhcn 节会自动按需要扩容（不再固定 16 KB）
  4. 新增 收集崩溃信息.bat
  4. 安装/应用脚本会把"写了多少条、跳过多少条、为什么跳过"打印清楚

注意：
  - 安装/修改时会自动备份原文件为 *.zhCN-backup
  - 游戏重新构建 / 启动器更新会覆盖成官方版，届时重新运行对应 .bat 即可
  - 本补丁基于官方源码修改，GPL-3.0-or-later；不包含游戏本体，也不含任何厂商 SDK 文件
