# Longshot 中文化补丁（简体中文）

给 **Longshot**（塞尔达传说：时之笛 PC 原生移植版）和 **Longshot Launcher**（构建/启动器）补全中文界面的补丁。

> 官方版本自带部分机器翻译，但 v3.1.1 / 启动器 v1.2.0 里仍有大量界面文字是英文（NFC 页、存储页、CRT 滤镜、物品栏编辑器、输入录制等新功能都没进翻译表，启动器 NFC 页甚至是硬编码英文）。本补丁把这些全部补成简体中文，并额外生成对应的繁体中文（游戏菜单内）。

**特色**
1. **道具名/地点名全部采用游戏官方中文译名** —— 直接从游戏本体的文本库（`texts\cnzh.product.110.sarc.zs`）里提取，与游戏内暂停菜单、地图、对话里看到的名字完全一致（例如 科奇里之剑、重铁靴、浮空靴、海拉鲁平原、科奇里森林、格鲁德之谷）。
2. **译名可以自己改** —— 见下面「四、自定义译名」。

---


### v1.3.1 重要说明（安装方式变了）

**不再替换整份 `longshot_vk.dll`，改成把译名写进你自己电脑上原本那份 DLL。**

原因：不同来源的 Longshot v3.1.1 构建并不相同（官方预编译版和启动器在你机器上编译出来的版本，菜单翻译表分别是 1199 条和 704 条，构建号也不一样）。把别人构建的 DLL 直接覆盖过去，会出现"进游戏、载入存档时崩溃"。v1.3.1 的做法是：

- 只追加一个 `.zhcn` 节存放译文，改翻译表里的指针；**代码段一个字节都不动**，所以不可能和你的构建不匹配；
- 翻译表里**没有**的条目（旧版/自己编译的构建里道具名是硬编码英文字面量），改成**就地改写**那些英文字符串——中文的 UTF-8 字节数必须不超过英文原名的字节数，超了脚本会告诉你哪几条需要改短。

### v1.3.0 说明

v1.2.0 附带的 DLL 是重新编译的版本，有玩家反馈进游戏后崩溃。v1.3.0 改回**已验证稳定**的编译结果，官方译名通过本补丁自带的「自定义翻译」机制写入 DLL 数据区。

## 一、适用范围

| 项目 | 适用版本 | 说明 |
|---|---|---|
| 游戏内菜单（Insert 菜单） | Longshot **v3.1.1** | 把译名写进 `bin\longshot_vk.dll`（不替换整份文件） |
| 启动器界面 | Longshot Launcher **v1.2.0 / v1.3.0** | 替换 `LongshotLauncher.exe` |

⚠️ 其它版本不保证兼容。游戏版本可在游戏文件夹的 `longshot_version.txt` 里看到（`source=` 就是构建号）；启动器版本可在启动器窗口标题看到。

## 二、安装（推荐：直接下载发布包）

1. 打开 [Releases](../../releases) 页面，下载最新的 `Longshot-zhCN-*.zip`。
2. 解压到任意位置（**要整个文件夹一起解压**，不要只拿 .bat 出来）。
3. 先完全退出游戏和启动器。
4. 双击 **`安装游戏汉化.bat`** —— 自动找到游戏文件夹，把译名写进**你这个文件夹里的** `bin\longshot_vk.dll`（原文件备份成 `.zhCN-backup`）。
5. 双击 **`安装启动器汉化.bat`** —— 自动找到已安装的启动器、备份并替换。
6. 打开启动器 → 界面应为中文；进入游戏按 **Insert** → 菜单应为中文。

脚本找不到安装位置时，会提示你粘贴路径，照着提示操作即可。
脚本最后会打印**写了多少条、就地改写多少条、跳过多少条（以及为什么跳过）**，那是排查问题最有用的一段文字。

### 让菜单显示中文的两个前提

- 游戏语言是简体中文：游戏文件夹的 `language.txt` 里那一行是 `zh-Hans`（官方中文版默认如此）。
- 菜单语言是「自动（跟随游戏语言）」：Insert 菜单 → `语言` 页 → 菜单语言 → 自动。也可以直接选「简体中文」。

## 三、还原

双击 **`还原原版.bat`**，会用安装时自动备份的 `.zhCN-backup` 文件把原版恢复回去。

（如果你通过启动器的「重新构建」把游戏升级/重建过，游戏文件本来就已经是官方版了，只有需要时才用还原脚本。）

## 四、自定义译名（想改哪个名字就改哪个）

某个道具或地点的译名不合你意？**不用重新编译**，改个文本文件就行：

1. 先退出游戏。
2. 用记事本打开 **`自定义翻译.txt`**（UTF-8 编码，记事本默认即可）。
3. 找到那一行，把等号右边改成你想要的译名，例如：

   ```
   Kokiri Sword = 克奇利之剑
   Hyrule Field = 海拉尔平原
   ```
   等号左边是游戏里的英文原名（**不要改**），右边随便写（中文英文都行，长度不限）。等号右边留空 = 这一项保持不动。
4. 保存，双击 **`应用自定义翻译.bat`**。
5. 重开游戏、按 Insert 打开菜单即可看到（几秒完成，不需要重新构建）。

**能改的内容**：物品栏全部 86 个道具名、传送列表 31 个地点名，以及 装备/道具/面具/强化/重要物品 等分类名。

**想恢复**：把那一行改回原来的译名（文件里都写着默认值）再运行一次即可。

**原理**（给好奇的人）：脚本给 `longshot_vk.dll` 追加一个 `.zhcn` 节存放译文，再把语言表里对应条目的指针指向新文本；语言表里没有的名字，则直接在 DLL 里把那段英文字符串就地改写成中文（因此中文不能比英文原名长）。原文件自动备份成 `.zhCN-backup`，随时可以还原。

## 五、更新后怎么办

- **启动器更新**：官方更新会覆盖成英文版。等本补丁适配新版本后再装，或者直接用当前版本（启动器不更新也能正常用）。
- **游戏重新构建/更新**：会换成官方英文 DLL。等本补丁适配新版本，或自行按下面的「自行构建」把翻译编译进新版。
- 重新构建/更新后，自定义译名需要重新运行一次 `应用自定义翻译.bat`（旧的 DLL 已被替换）。

## 六、本补丁改了什么

### 游戏内菜单（`longshot_vk.dll`）
- 在 `gpu/vk/menu_i18n.h` 的中文表里补了 **415 条**菜单界面翻译（画面/音频/游戏/按键设置/NFC/调试 各页的标签、说明、选项名）。
- 补了 **86 个物品栏道具名 + 31 个传送地点名**，全部使用**游戏官方中文译名**（从游戏本体文本库提取：科奇里之剑、大师之剑、海利亚盾、重铁靴、浮空靴、妖精之弓、海拉鲁平原、科奇里森林、格鲁德之谷……），以及 **装备/道具/面具/强化/重要物品** 分类名和 **地上/迷宫** 分组名。
- 繁体中文表由简体自动转换生成，同步补齐。

### 启动器（`LongshotLauncher.exe`）
- 中文词条从 700 条补到 **1147 条**（设置页、存储页、主页、拉取请求、存档编辑器等）。
- **把 NFC 页面从硬编码英文改为接入翻译系统**（`NfcView.axaml` 21 处文字、`NfcViewModel.cs` 16 处字符串），所以 NFC 页现在是中文。

### 保留英文的部分
- 品牌名：NVIDIA DLSS / DLAA / Reflex、AMD FSR、Intel XeSS、Lanczos、CRT 预设名等（业界惯例保留）。
- 游戏崩溃/报错弹窗（官方所有语言版本都是英文）。
- 少数技术标识（环境变量名、日志行）。

## 七、自行构建（给想自己编译的人）

本仓库 `source/` 下是改动后的源文件，可作为 GPL 对应的「可构建源代码」。

**游戏 DLL**（需要已装好官方 Longshot v3.1.1 及其构建工具）：
1. 把 `source/menu_i18n.h` 覆盖到
   `%LOCALAPPDATA%\LongshotLauncher\toolchains\v3.1.1\LongshotBuilder\tools\gpu\vk\menu_i18n.h`
2. 用命令行重新构建（关闭游戏后执行）：
   ```bat
   set TOOLS=%LOCALAPPDATA%\LongshotLauncher\toolchains\v3.1.1\LongshotBuilder\tools
   set PYTHONUTF8=1
   "%TOOLS%\python\python.exe" -I "%TOOLS%\nx2\make_game.py" --update "C:\Games\Longshot\stable\v3.1.1" --work "C:\Games\Longshot\LongshotLauncher\work" --fetch-ngx-sdk --accept-nvidia-license
   ```
   约 10 分钟；构建完 `bin\longshot_vk.dll` 就是中文版。

**启动器**（需要 .NET 10 SDK）：
1. 克隆官方源码 https://git.magicbean.dev/MagicBeanDev/LongshotLauncher ，检出 `v1.2.0`。
2. 用 `source/launcher/` 里的文件覆盖对应的 `App/Views/NfcView.axaml`、`App/ViewModels/NfcViewModel.cs`、`Core/Lang/zh-Hans.json`。
3. 构建：
   ```bat
   dotnet publish App/LongshotLauncher.csproj -c Release -r win-x64 --self-contained ^
     -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=none ^
     -p:LongshotTag=v1.2.0 -p:Version=1.2.0 -o out
   ```

## 九、常见问题

**Q：装了之后菜单还是英文？**
A：按顺序看三件事：① `language.txt` 是不是 `zh-Hans`；② Insert 菜单 → `Language / 语言` → `Menu language / 菜单语言` 是不是「简体中文」或 `Auto (game's language)`（**这一项如果停在英文上，菜单就整页都是英文**，和补丁无关）；③ 补丁装的是不是**正在玩的那个**游戏文件夹（启动器里能看到每个构建的文件夹路径）。

**Q：脚本说"修改了 4 条 / 找不到对应英文名"？**
A：说明你这份 DLL 的菜单翻译表比补丁制作的版本小（官方预编译版是 1199 条，自己编译的旧版可能只有 704 条），那些名字不在表里。v1.3.1 会自动转到"就地改写硬编码英文名"的方式；如果还是改不到，说明这份构建的界面文字是写死在代码里的，只能等适配——或者把游戏换成官方预编译版（`longshot_version.txt` 里 `source=` 与别人一致、没有 `builder=` 那一行）再装。

**Q：装完进游戏、载入存档就崩？**
A：v1.3.1 之前会发生：旧版安装器是整份替换 DLL，你的游戏构建和补丁里的 DLL 构建不一致就会崩。用 v1.3.1 的 `安装游戏汉化.bat`（先双击 `还原原版.bat` 再用新版安装）即可，代码段不会被改动。

**Q：改了 `自定义翻译.txt` 但游戏里没变？**
A：按顺序检查：① 游戏是否已退出（脚本运行时会提示）；② 双击的是 `应用自定义翻译.bat` 而不是只保存文件；③ 菜单是否重开过（Insert 关掉再开）；④ 等号左边是否和文件里的英文原名完全一致（区分大小写和空格）；⑤ 脚本有没有提示"中文比英文原名长，原位放不下"（把译名改短）。

**Q：启动器打开报错/被 Windows 拦截？**
A：本补丁只是把官方 exe 换成了我们自己用官方源码重新编译的版本（无数字签名，Windows 可能提示"未知发布者"，点"仍要运行"）。

**Q：杀毒软件报毒？**
A：`.bat` 只是调用 PowerShell 复制/修改文件，可自行打开查看内容。exe/dll 为官方源码自行编译。

**Q：游戏更新后中文没了？**
A：正常，更新会覆盖文件。见上面「更新后怎么办」。
